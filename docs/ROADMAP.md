# Roadmap

## Done

  development, case studies, commercial projects, skills, certifications, CV, contact).
- Personal BD Workspace core: account prioritisation, stakeholder mapping, discovery briefs,
  opportunity mapper, deal coach, outreach drafts, follow-ups, personal BD metrics.

## Next (highest value first)

2. "Current company" configuration in the workspace settings (pending full requirements).
3. Reposition CRM-like screens into a personal intelligence layer (win/loss learning,
   commercial notes, frameworks, personal development) — see the evaluation in the pivot notes.
4. Login + sync (Supabase) before storing anything sensitive.

## Explicitly not planned
Replacing the employer's CRM, scraping, bulk messaging, fake achievements or testimonials.
